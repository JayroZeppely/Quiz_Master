À propos de l'application

Présentation

Ce site est une plateforme proposant un ensemble de quiz intéractifs sur différents sujets. Cette plateforme permet aux utilisateurs de tester leurs connaissances sur divers sujets.

L'objectif est de rendre l'apprentissage amusant et interactif en permettant aux utilisateurs de s'exercer sur des sujets qui les intéressent.

Structure

Le site est organisé en plusieurs sections :

  • La page d'accueil présente les différents quiz disponibles.
  • Les pages de quiz permettent aux utilisateurs de répondre aux questions.
  • La page des résultats affiche le score et les réponses correctes.
  • La page actuelle présente les informations sur la plateforme.

Technologies utilisées

Le site est développé en utilisant les technologies suivantes :

  • Angular pour le développement front-end.
  • TypeScript pour la logique de l'application.
  • HTML et CSS pour la structure et le style des pages.
